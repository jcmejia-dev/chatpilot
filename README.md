# ChatPilot

ChatPilot is a browser-based training simulator for handling multiple subscriber conversations with human-reviewed AI-style coaching.

## Features

- Multi-subscriber inbox with separate personalities, moods, and conversation histories
- Context-aware coaching for objections, complaints, casual chats, and buying signals
- Editable suggested replies with human approval before sending
- Practice Shift mode with incoming messages, unread queues, response handling, and scoring
- Local analytics for reply quality, opportunity recognition, and missed messages
- No real subscriber data required
- GitHub Pages compatible

## Privacy and usage

This build uses simulated data only. Do not paste private subscriber information, employer data, credentials, or production conversations into the public demo. If you ever connect ChatPilot to a real workplace account, first confirm that your employer and platform permit external AI tools and data processing.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy to GitHub Pages

This repository includes a GitHub Actions workflow that publishes the static site from the repository root to GitHub Pages.
